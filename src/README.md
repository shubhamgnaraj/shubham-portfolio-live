# Work section integration

1. Copy `Work.jsx` into `src/components/Work.jsx` (or your preferred components folder).
2. Copy `Work.css` beside it.
3. Import and render `<Work />` after `<Hero />` in your page/App component.
4. The section uses the CSS variables already defined by your portfolio (`--paper`, `--ink`, `--orange`, `--muted`) and falls back to the same palette if needed.
5. Replace the placeholder `href: "#"` links in the `projects` array with your real demo and repository URLs before publishing.
6. The Airbnb preview uses a remote Unsplash image. Replace it with your own local image or a verified asset if you prefer a fully self-hosted portfolio.

Note: The WhatsApp and dashboard panels are CSS/React concept previews, not screenshots of a production app. Their labels explicitly call them concept previews to avoid implying they are real screenshots.
